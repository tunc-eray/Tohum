Kurulum ve Kodlar

GitHub'a yükleme

Tek dosya var: api/app.mjs. GitHub'da oluştur düğmesi dosya adı hazır olarak yeni dosya sayfasını açar. Kopyala ile aldığın kodu oradaki kutuya yapıştırıp Commit changes de.

Tek dosyayla kurulum (mevcut siteye dokunmaz)

  1. GitHub'da repona gir: Add file, Create new file. Dosya adı kutusuna api/app.mjs yaz (klasörü kendisi oluşturur).
  2. Aşağıdaki api/app.mjs kodunun tamamını Kopyala ile alıp yapıştır, Commit changes de. Başka hiçbir dosyaya dokunma.
  3. Vercel projesinde Storage bölümünden Upstash Redis ekle. Settings, Environment Variables bölümüne GEMINI_API_KEY ekle (anahtarı koda yazma).
  4. Yeniden yayınla (Redeploy), sonra tohum-secici.vercel.app/api/app adresini aç. Kişi simgesinden hesap aç, API anahtarın orada görünür.
  5. Anahtarı Deneyap koduna yaz (alttaki ikinci dosya), Wi-Fi bilgilerini gir, karta yükle.
